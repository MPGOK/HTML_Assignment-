README.MD
This project main objected was to create a website with multiple pages of both html and css. 

My topic of choice was trombone and as you can see from the pages here we have the theme covers various aspects such as a homepage and live events, musicians, trombones etc. 

The purpose of this is projec is aim to show a smooth transition between each page of the website. 

Each individaul page has various styles and grids making up the page. 

Index:
Has a 2 grid system with introductory text which encourage moving though the website as they link across the main pages such as lives events, musicians and trombones. 

The header and footer are created here and are utilised acorss the whole project. This was managed through calling the style sheet of inedx on all content pages which applied the conditions created by the index css. 

Live events: 
Has a similar layout but has more content in terms of images of a spotlight musician. 

As well as a more detailed text content helping to build your knowledge on teh toppic. 

Musicians: 
Utilises a 4 grid system that has a floating qutoe box within each grid square and has an italic and colour selection diffenret fromt the normal text helping to aid in front end users engagement. 

Trombones:
Has a 3x2 , 6 grid visually, system that has a mixture of various texts, images and videos. 

Testimonials: 
Has an 8 grid system and is a larger version of that on musicians. 

Membership:
Contains and package plan with variosu sizes texts and images that help engage with the display and users involvement on teh content. 

Contact Us: 
Has a unique form entrance on its page to act like a newletter sign up sheet.
